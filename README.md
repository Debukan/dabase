# README for Study Answers App

## Описание проекта

Study Answers App — это веб-приложение, предназначенное для обмена ответами на задания по информатике. Пользователи могут выбирать задания с различных сайтов и находить решения, отсортированные по темам и номерам.

## Стек технологий

- **Frontend**: React + TypeScript
- **Backend**: FastAPI (Python)
- **База данных**: PostgreSQL

## Установка

### Frontend

1. Перейдите в директорию `frontend`.
2. Установите зависимости:

   ```
   npm install
   ```

3. Запустите приложение:

   ```
   npm start
   ```

### Backend

1. Перейдите в директорию `backend`.
2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Запустите приложение:

   ```
   uvicorn app.main:app --reload
   ```

## Использование

- Перейдите на главную страницу, чтобы выбрать сайт с заданиями.
- Используйте панель поиска для нахождения заданий по номеру или ключевым словам.
- Просматривайте ответы, отсортированные по темам.
